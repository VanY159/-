# Буря Стихій

3D-файтинг у браузері (Three.js): чотири бійці-стихії, суперсили, комбо, бій до двох перемог і добивання в кінці.
Відкрий `index.html` у браузері (потрібен інтернет для Three.js з CDN). Працює на комп'ютері (клавіатура) і на телефоні (сенсорні кнопки).

| | Гравець 1 | Гравець 2 |
|---|---|---|
| Рух / стрибок | A D / W | ← → / ↑ |
| Блок | S | ↓ |
| Рука / нога | J / K (або F / G) | , / . (або Num1 / Num2) |
| Сила (¼ енергії) | L (або H) | / (або Num3) |
| Супер (повна енергія) | I (або T) | ; (або Num0) |

Бійці: **Вогнар** (вогняна куля), **Крижана** (спис, що заморожує), **Громобій** (телепорт за спину), **Тінь** (хвиля по землі, що краде здоров'я).
