# Бобі: офлайн-бот, який реагує на слова й дотики

Анімований робот, що живе у браузері телефона чи комп'ютера та **працює без інтернету**.
Його «штучний інтелект» (локальна модель розуміння мови, емоції та пам'ять) виконується прямо на пристрої:
нічого не надсилається на сервери.

## Що вміє

**Дотики**
| Жест | Реакція |
|---|---|
| Тап по тілу, оку, антені, животику, руці | для кожної частини своя реакція (кліпає, б'ється «струмом», хихоче, дає п'ять) |
| Повільне погладжування | муркоче, сердечка, настрій кращає, злість минає |
| Довге натискання | обійми 🤗 |
| 2 швидкі тапи | стрибок |
| 3 і більше швидких тапів | лоскотання, сміється |
| 10 тапів за 3 секунди | сердиться 😠 |
| Швидкий змах | бот відлітає на пружині, при сильному змаху паморочиться голова |
| Струшування телефона | «землетрус!» |
| Тап по порожньому місцю | бот дивиться туди |

**Слова** (текстом або голосом 🎤)
- розмова: привітання, «як справи», компліменти, образи, вибачення, «я тебе люблю», «мені сумно»…
- команди: «танцюй», «заспівай», «стрибни», «покрутись», «засмійся», «спи», «прокидайся»
- корисне: «котра година», «яке сьогодні число», «скільки буде 15 * 4 + 2»
- пам'ять: «мене звати Оля», «як мене звати», «тебе звати Робік»,
  «запам'ятай, що кіт — це пухнастик» → «що таке кіт», «що ти пам'ятаєш», «забудь усе»
- **навчання**: «коли я кажу банан, відповідай смачно!». А якщо бот чогось не зрозумів, напиши «відповідай: …», і він запам'ятає відповідь

**Емоції.** У бота є радість, злість, прихильність і енергія. Вони змінюються від слів і дотиків
та впливають на вираз обличчя, колір, відповіді й реакції. Якщо довго не гратися, бот нудьгує й засинає.

## Як працює ШІ

`brain.js` перетворює фразу на вектор ознак: слова, основи слів, пари слів і символьні триграми з вагами TF-IDF.
Намір визначається за косинусною схожістю з навчальними прикладами, тому бот розуміє і фрази з помилками
(«прівіт», «як спрaви», «потанцуй»). Фрази, яких користувач навчив, додаються в модель, і вона одразу перенавчається.
Пам'ять зберігається в `localStorage` на пристрої.

## Запуск

**Найпростіше:** відкрий `index.html` у браузері.

**Як застосунок на телефоні (повністю офлайн):**
1. Розмісти папку на будь-якому статичному хостингу (наприклад, GitHub Pages) або запусти локально:
   `python3 -m http.server 8000` і відкрий `http://localhost:8000`.
2. Відкрий сторінку один раз з інтернетом і натисни в меню браузера **«Додати на головний екран»**.
3. Далі застосунок працює без мережі: service worker (`sw.js`) кешує всі файли.

### Про голос
- **Голос бота** (синтез мовлення) працює офлайн, якщо в системі встановлено голос для української мови
  (Android: Налаштування → Мова → Синтез мовлення → Google → Українська).
- **Розпізнавання голосу** залежить від браузера. Android Chrome розпізнає офлайн, якщо встановлено
  офлайн-пакет української мови (Google → Голос → Офлайн-розпізнавання мовлення). Деякі браузери
  розпізнають голос лише з інтернетом; тоді бот про це скаже, а писати текстом можна завжди.

## Файли
- `index.html`, `style.css`: інтерфейс
- `bot.js`: малювання й анімація (пружинна фізика, міміка, частинки)
- `brain.js`: розуміння мови, відповіді, пам'ять і навчання
- `app.js`: емоції, жести, голос, головний цикл
- `sound.js`: звуки, синтезовані через WebAudio (без аудіофайлів)
- `sw.js`, `manifest.webmanifest`, `icon.svg`: офлайн-режим і встановлення як застосунок
