# Піп — Епізод 1: «Повінь» (2.5D, згенеровано кодом)

Вертикальне відео 1080×1920, 30 fps, 2:30. Усе зроблено кодом, без AI-сервісів, стокових картинок і семплів:

- **Графіка** — власний 2.5D-рушій на Canvas 2D: перспективна камера (dolly, crane, orbit, whip pan, crash zoom, handheld), паралакс-шари, тумани, дощ у 3D, блискавки, бризки, motion blur, rack focus, кольорокорекція й зерно плівки.
- **Персонажі** — векторні коти, що малюються процедурно (сидячи, у бігу, лежачи, зі спини, згори, крупний план ока).
- **Звук** — синтез у Node.js: фортепіано (адитивний синтез), піцикато (Karplus–Strong), струнні та хор (saw + форманти), тайко, бочка, удари, а також дощ, грім, вода, бризки, скрип, нявкання (форманти «мі-а-у»), серцебиття, пташки. Ревербератор Freeverb, лімітер, ~-14.5 LUFS.

## Як зібрати

Потрібні Node 18+, ffmpeg, Playwright із Chromium.

```bash
node audio.mjs                         # out/audio.wav
node render.mjs --workers 3            # out/pip_ep1_en.mp4, out/pip_ep1_uk.mp4
node preview.mjs out/check.png 1.5 40 97 --sheet   # контрольні кадри
```

## Структура

| Файл | Що робить |
|---|---|
| `src/engine.js` | камера, проекція, шари, дощ, блискавки, титри |
| `src/cats.js` | персонажі та реквізит (пліт, коробка, ящики, пляшки) |
| `src/world.js` | світи: міст і річка, вулиця, вулиця-канал, кімната, провулок, підводна сцена, світанок |
| `src/scenes.js` | таймлайн: 13 сцен, рух камери, титри EN/UA |
| `audio.mjs` | музика та SFX за тим самим таймлайном |
| `render.mjs` | паралельний рендер → x264 → склейка → AAC |

Таймлайн відповідає сценарію: хук 0–3 с, «12 годин тому», буря, повінь, «Ніхто не допоміг», будівництво плоту, провал, «Але він не здався», погоня, міст, порятунок мами, обвал мосту, світанок і питання «А ти б їй допоміг?» + «Частина 2».
